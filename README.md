# GD Skin Studio

Android-приложение + сайт для скачивания.

## Что находится в проекте
- `index.html` — сайт-витрина, кнопки ведут на GitHub Releases.
- `app/` — Android-приложение на Kotlin с редактором внутри WebView.
- `.github/workflows/android.yml` — автоматическая сборка APK на GitHub Actions.

## Как загрузить проект
Загрузи **содержимое** этого архива в корень репозитория `stefcuber14-alt/GD-Skin-Studio` (не загружай ZIP как единственный файл). В GitHub: Add file → Upload files → выбери все файлы и папки проекта → Commit changes.

## Как получить APK
1. После загрузки открой вкладку Actions и дождись успешной сборки.
2. APK можно скачать из Artifacts соответствующего запуска.
3. Чтобы опубликовать APK по постоянной ссылке на сайте, открой Releases → Draft a new release, создай тег `v1.0.0` и опубликуй релиз. Либо создай тег `v1.0.0` — workflow соберёт APK и прикрепит его к релизу автоматически.

Сайт использует адрес последнего релиза и ожидает файл `GD-Skin-Studio.apk`.

## Важно
- Сейчас это стартовая версия редактора, а не полная копия Geometry Dash.
- Оригинальные игровые спрайты не включены. Можно загружать собственные изображения-ориентиры.
- APK собирается автоматически GitHub Actions; в этом архиве готового APK нет.
- Для публикации в Google Play потребуется отдельная подписанная release-сборка и настройка подписи. Не публикуй debug APK как официальный релиз для широкой аудитории.
